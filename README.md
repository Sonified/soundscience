# soundscience.now.audio

Public home for the accepted author version of:

**Sound Science: Audifying the Sun** — Robert Alexander,
*IEEE Computer Graphics & Applications*, 2026.
DOI: https://doi.org/10.1109/MCG.2026.3694282

`/` redirects to the PDF. Hosted here (rather than on a `*.pages.dev`
subdomain) because free shared-hosting domains are blocklisted wholesale
by LinkedIn's link scanner, which threw an unsafe-link warning on the
previous URL.
